# Tribo Project

Um projeto criado originalmente no Replit e agora hospedado no GitHub.

## 📋 Descrição

Tribo é um projeto Node.js/TypeScript que foi desenvolvido na plataforma Replit.

## 🛠️ Tecnologias

- **Node.js** com pnpm
- **TypeScript**
- **Workspace monorepo** (pnpm-workspace)

## 📦 Instalação

```bash
# Instalar dependências
pnpm install
```

## ▶️ Execução

```bash
# Executar scripts disponíveis
pnpm run <script-name>
```

Verifique o `package.json` para ver os scripts disponíveis.

## 📁 Estrutura do Projeto

```
├── lib/          # Código-fonte principal
├── scripts/      # Scripts adicionais
├── package.json  # Dependências do projeto
└── README.md     # Este arquivo
```

## 🔧 Configuração

- `tsconfig.json` - Configuração do TypeScript
- `pnpm-workspace.yaml` - Configuração do workspace pnpm
- `.replit` - Configuração original do Replit
